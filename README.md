# BugBounty-Playbook

Bug Bounty（バグバウンティ）で必要な知識・手法・ツールを体系化したプレイブックです。  
実際の企業サービスを対象にした脆弱性調査に特化しています。

---

## 📘 章構成

### 1. Recon（偵察）
- Subdomain Enumeration  
- Asset Discovery  
- Wayback / JS Analysis  

### 2. Web Exploitation
- SQLi / XSS / SSRF / RCE  
- Authentication Bypass  
- Business Logic Bugs  

### 3. API Testing
- Broken Auth  
- Rate Limit  
- Mass Assignment  

### 4. Cloud Misconfiguration
- AWS / GCP / Azure  
- Public Bucket  
- IAM Misconfig  

### 5. Reporting
- 再現手順  
- 影響度  
- 修正案  

---

## 🧪 使用ツール
- Burp Suite  
- amass  
- subfinder  
- httpx  
- ffuf  

---

## 🎯 目的
- 実際のサービスの脆弱性を発見する  
- 再現性のあるレポートを作成する  
- 報奨金獲得につながる知識を体系化する
